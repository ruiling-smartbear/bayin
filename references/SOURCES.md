# Reference recordings

Real instruments, for measuring against. `./fetch.sh` downloads them; they are not in the
repository. All are from Wikimedia Commons.

| Name | For | Commons file | License |
|---|---|---|---|
| assembly | bugle | [Assembly bugle call.ogg](https://commons.wikimedia.org/wiki/File:Assembly_bugle_call.ogg) | Public domain |
| taps | bugle | [Taps on bugle.ogg](https://commons.wikimedia.org/wiki/File:Taps_on_bugle.ogg) | Public domain |
| k5la | air horn | [AirChime K5LA.ogg](https://commons.wikimedia.org/wiki/File:AirChime_K5LA.ogg) | CC0 |
| nathan-m5 | air horn | [Nathan M5.ogg](https://commons.wikimedia.org/wiki/File:Nathan_M5.ogg) | CC0 |
| up844 | steam whistle | [2010 UP844 Whistle.ogg](https://commons.wikimedia.org/wiki/File:2010_UP844_Whistle.ogg) | CC BY-SA 3.0 |
| c57 | steam whistle | [C57180.kiteki.1.ogg](https://commons.wikimedia.org/wiki/File:C57180.kiteki.1.ogg) | CC BY-SA 4.0 |

Measure one with `python3 tools/measure.py notes references/assembly/assembly.wav`.
